# R.T.M Météo Moba

Météo en temps réel des 34 localités du territoire de Moba (Tanganyika, RDC) — R.T.M Radio Télévision Moba.

Application installable sur iPhone (Safari → Partager → « Sur l'écran d'accueil »), Android (Chrome → « Installer l'application ») et Windows (Edge/Chrome → « Installer »).

Données : Open-Meteo · Positions GPS : GRID3 / Ministère de la Santé.
